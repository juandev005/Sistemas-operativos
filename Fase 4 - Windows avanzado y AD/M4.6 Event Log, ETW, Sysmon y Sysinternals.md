# M4.6 — Event Log, ETW, Sysmon y Sysinternals
↑ [[F4 Índice]] · Anterior: [[M4.5 Autenticación NTLM y Kerberos]] · Siguiente: [[F5 Índice]]

**Objetivo:** dominar la telemetría de Windows; corazón del trabajo diario de un analista SOC.
**Prerrequisitos:** M4.5, M3.5, M3.7.
**Herramientas:** `Get-WinEvent -FilterHashtable`, `wevtutil`, toda la Sysinternals Suite.

## Conceptos clave
4688 + Sysmon EID 1 = creación de proceso con línea de comandos y padre (base de detección de LOLBins) · 1102 como señal de evasión · Sysmon como "auditd de Windows" (ver [[M2.6 Logs - journald, syslog y auditd|M2.6]])

## Event IDs clave (tarjetas)
| ID | Significado |
|---|---|
| 4624 / 4625 | Logon exitoso (con logon type) / fallido |
| 4634 / 4647 | Cierre de sesión |
| 4672 | Privilegios especiales asignados |
| 4688 | Creación de proceso (con línea de comandos si está habilitado) |
| 4720 | Creación de cuenta |
| 4722 / 4724 / 4728 / 4732 | Cambios de cuenta/grupo |
| 4698 | Creación de tarea programada |
| 7045 | Instalación de servicio nuevo (System) |
| 7034 / 7036 | Estado de servicios |
| 4768 / 4769 / 4771 | Kerberos |
| 4776 | NTLM |
| 1102 | Borrado del log de seguridad |
