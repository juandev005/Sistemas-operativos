# M4.4 — Active Directory: dominio, LDAP y GPO
↑ [[F4 Índice]] · Anterior: [[M4.3 Redes Windows - SMB, RDP, WinRM y firewall]] · Siguiente: [[M4.5 Autenticación NTLM y Kerberos]]

**Objetivo:** entender el núcleo de identidad de las empresas, donde ocurre la mayoría de los incidentes.
**Prerrequisitos:** M3.6, M4.3.
**Herramientas:** `Install-ADDSForest`, `Get-ADUser`, `Get-ADComputer`, `gpresult`, `dsquery`.

## Conceptos clave
AD como gran objetivo · GPO como mecanismo de control masivo · LDAP como lenguaje de enumeración (lo usan los atacantes con BloodHound)

## Laboratorios
- [ ] Construir el dominio (DC + cliente Windows 11 unido)
- [ ] Crear OUs, usuarios y grupos
- [ ] Aplicar una GPO (política de contraseñas o banner de login) y verificarla con `gpresult`

## Recursos
Microsoft Learn (AD DS) · TryHackMe módulos de AD

## Criterio de dominio
- [ ] Levanto un dominio funcional
- [ ] Creo objetos y aplico/verifico una GPO
- [ ] Explico el papel de LDAP y DNS
