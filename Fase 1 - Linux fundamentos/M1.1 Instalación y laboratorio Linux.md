# M1.1 — Instalación y montaje del laboratorio Linux
↑ [[F1 Índice]] · Siguiente: [[M1.2 La shell y Bash]]

**Objetivo:** tener Linux en 3 modalidades (VM, WSL, contenedor) y saber cuándo usar cada una.
**Prerrequisitos:** M0.1, M0.2, M0.5, M0.6.
**Herramientas:** VirtualBox/VMware, `wsl --install`, `docker run -it ubuntu bash`.

## Conceptos clave
Snapshot como red de seguridad · diferencia operativa VM vs WSL vs contenedor

## Laboratorios
- [ ] Ubuntu 26.04 LTS en VirtualBox con snapshot "post-install limpio"
- [ ] `ubuntu` en WSL2
- [ ] `docker run -it --rm debian:13 bash` y comparar los tres entornos

## Recursos
help.ubuntu.com · docs de VirtualBox · Microsoft Learn (WSL)

## Criterio de dominio
- [ ] VM Ubuntu con snapshots
- [ ] Explico cuándo usar VM vs WSL vs contenedor
- [ ] Restauro un snapshot sin ayuda
