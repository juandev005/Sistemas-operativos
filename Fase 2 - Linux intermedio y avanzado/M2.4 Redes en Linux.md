# M2.4 — Redes en Linux
↑ [[F2 Índice]] · Anterior: [[M2.3 Gestión de paquetes]] · Siguiente: [[M2.5 Almacenamiento, LVM y sistemas de archivos]]

**Objetivo:** configurar, diagnosticar y asegurar la red desde Linux; aterrizar TCP/IP de M0.6.
**Prerrequisitos:** M2.1, M0.6.
**Herramientas:** `ip`, `ss`, `dig`, `nft`/`iptables`, `ufw`, `ssh`, `scp`, `tcpdump`.

## Conceptos clave
`ss -tulpn` para ver qué escucha (triaje SOC) · SSH como vector y objeto de hardening · DNS como canal de exfiltración

## Laboratorios
- [ ] SSH con clave; deshabilitar login de root y por contraseña
- [ ] Inventariar servicios a la escucha con `ss -tulpn`
- [ ] Reglas nftables básicas (permitir SSH, denegar el resto)
- [ ] Capturar y leer tráfico DNS con `tcpdump`

## Recursos
wiki.nftables.org · man `ip(8)`, `ss(8)`, `sshd_config(5)` · *The Linux Command Line* 3.ª ed. (networking)

## Criterio de dominio
- [ ] Diagnostico conectividad y DNS
- [ ] Leo `ss -tulpn` para triaje
- [ ] Endurezco SSH
- [ ] Escribo reglas de firewall básicas
