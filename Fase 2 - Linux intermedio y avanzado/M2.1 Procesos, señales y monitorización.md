# M2.1 — Procesos, señales y monitorización
↑ [[F2 Índice]] · Siguiente: [[M2.2 systemd y servicios]]

**Objetivo:** observar y controlar la ejecución en vivo.
**Prerrequisitos:** M0.3, M1.4.
**Herramientas:** `ps`, `top`, `htop`, `pstree`, `kill`, `strace`, `lsof`, `nice`.

## Conceptos clave
Árbol padre-hijo (clave para detectar ejecuciones anómalas) · señales como IPC básica

## Laboratorios
- [ ] `strace ls` e identificar `open`/`read`/`write` (cierra el bucle de M0.2)
- [ ] Lanzar un proceso, suspenderlo, reanudarlo y matarlo con distintas señales
- [ ] `lsof` para ver archivos/puertos de un proceso

## Recursos
*The Linux Command Line* 3.ª ed. (procesos) · *The Linux Programming Interface* (Kerrisk)

## Criterio de dominio
- [ ] Interpreto la salida de `ps aux`
- [ ] Mato procesos con la señal correcta
- [ ] Leo un `strace` básico
