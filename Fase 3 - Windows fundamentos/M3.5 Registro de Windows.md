# M3.5 — El Registro de Windows
↑ [[F3 Índice]] · Anterior: [[M3.4 NTFS - MFT, ADS y ACL]] · Siguiente: [[M3.6 Usuarios, SID, tokens y UAC]]

**Objetivo:** entender la base de datos de configuración y sus claves de persistencia.
**Prerrequisitos:** M3.4.
**Herramientas:** `reg query`, `Get-ItemProperty`, `regedit`, Autoruns.

## Conceptos clave
Claves `Run` como persistencia clásica (MITRE T1547) · hives como artefactos forenses ricos

## Laboratorios
