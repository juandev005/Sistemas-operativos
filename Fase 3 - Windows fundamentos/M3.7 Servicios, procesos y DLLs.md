# M3.7 — Servicios, procesos, hilos y DLLs en Windows
↑ [[F3 Índice]] · Anterior: [[M3.6 Usuarios, SID, tokens y UAC]] · Siguiente: [[M3.8 CMD y PowerShell fundamentos]]

**Objetivo:** cómo se ejecuta y organiza el código en Windows.
**Prerrequisitos:** M3.6.
**Herramientas:** `sc query`, `tasklist /svc`, `Get-Service`, `Get-Process`.

## Conceptos clave
`svchost.exe` legítimo vs anómalo · DLL hijacking y side-loading (LOLBins, Fase 5) · orden de búsqueda de DLLs
