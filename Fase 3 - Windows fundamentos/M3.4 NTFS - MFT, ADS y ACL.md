# M3.4 — NTFS: MFT, ADS, permisos y ACL
↑ [[F3 Índice]] · Anterior: [[M3.3 Arranque de Windows]] · Siguiente: [[M3.5 Registro de Windows]]

**Objetivo:** dominar el sistema de archivos de Windows, pieza central del forense.
**Prerrequisitos:** M3.2, M0.5.
**Herramientas:** `icacls`, `dir /r`, `fsutil`, Streams (Sysinternals).

## Conceptos clave
La MFT como "inodo de Windows" y columna vertebral del forense · ADS como técnica de ocultación · SACL como base de la auditoría

## Laboratorios
- [ ] Crear un ADS (`echo oculto > archivo.txt:secreto`) y detectarlo con `dir /r` y Streams
- [ ] Leer/modificar ACL con `icacls`
- [ ] Observar las marcas de tiempo MACB de un archivo

## Recursos
*Windows Internals, Part 2* (capítulo NTFS) · Microsoft Learn (NTFS)

## Criterio de dominio
- [ ] Explico la MFT
- [ ] Detecto y creo un ADS
- [ ] Interpreto/manipulo ACL con `icacls`
