# M3.6 — Usuarios, grupos, SID, tokens y UAC
↑ [[F3 Índice]] · Anterior: [[M3.5 Registro de Windows]] · Siguiente: [[M3.7 Servicios, procesos y DLLs]]

**Objetivo:** modelo de identidad y seguridad de Windows.
**Prerrequisitos:** M3.5.
**Herramientas:** `whoami /all`, `whoami /priv`, `net user`, `net localgroup`, `Get-LocalUser`.

## Conceptos clave
SID como identidad real · tokens como portador de privilegios (robo de token) · logon types para el triaje de autenticación
